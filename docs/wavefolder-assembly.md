# Wavefolder (MOD-WF7) assembly notes

1. Populate the power section first and verify +/-12 V rails before fitting
   the analog board.
2. Fit the matched transistor pair last; thermal paste is not required but the
   pair must be tied with the supplied thermal clip.
3. Run the calibration firmware with the test jig connected. The trim table is
   written at the factory and should not be edited.
4. Panel revision: see the drawing number on the faceplate artwork.
